# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 2.4.x   | :white_check_mark: |
| < 2.4   | :x:                |

## Reporting a Vulnerability

The Radiant-Darwin engineering team takes security vulnerabilities seriously.
If you discover a security vulnerability in this project:

1. **Do not** disclose the issue publicly in GitHub Issues or discussions.
2. Please report security issues privately via GitHub Security Advisories or by emailing the maintainer at `jbrandonp@users.noreply.github.com`.
3. Provide detailed steps to reproduce the issue, including environment details and a minimal reproduction script.

You will receive an acknowledgment within 48 hours and regular updates on the resolution progress.
